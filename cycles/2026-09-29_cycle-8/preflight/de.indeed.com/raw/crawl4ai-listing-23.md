#### Vollständige Stellenbeschreibung
**Ihre Aufgaben**
  * Aufbau und Weiterentwicklung einer Teststrategie (Testpyramide) inkl. ISTQB-konformer Methodik

  * Erstellung von Testframeworks, Testdaten und wiederverwendbaren Utilities
  * REST API Testing (Contract/Integration), Mocking/Stubbing und Validierung von Fehlerfällen
  * UI-Testautomatisierung mit Selenium (falls relevant)
  * Integration der Tests in CI/CD mit Jenkins und/oder GitLab CI inkl. Reporting und Quality Gates
  * Testausführung und -isolierung in Docker-Umgebungen; Stabilisierung von Pipelines (Flaky Tests, Parallelisierung)
  * Analyse von Testergebnissen, Defect Triage, enge Zusammenarbeit mit Entwicklung (Root cause, Fix verification)
  * Automatisierung von Workflows mit Bash/Shell; Build-/Release-Support


**Ihr Profil**

  * Erfahrung mit ISTQB Zertifizierung (Foundation oder höher) und fundiertes Verständnis von Testmethoden
  * Sehr gute Kenntnisse in Python und Testframeworks (pytest/unittest)
  * Erfahrung in CI ( Jenkins und/oder GitLab CI ) und Versionsverwaltung (Git)
  * Praxis mit Docker für reproduzierbare Testumgebungen
  * Erfahrung mit REST API Testing (z. B. Requests, Postman/Newman, eigene Frameworks)
  * Strukturierte, qualitätsorientierte Arbeitsweise und gute Kommunikation mit Dev-Teams
  * Sehr gute Deutsch- und gute Englischkenntnisse
